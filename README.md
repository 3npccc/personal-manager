# 个人管理（personal-manager）

一个**纯本地、不联网**的 Windows 桌面端个人管理工具。基于 Flutter 3.47 +
Dart 3.13 + drift（SQLite）构建。

---

## 一、它能做什么

左侧导航共 **9 项**：

| # | 页面 | 说明 |
| - | ---- | ---- |
| 1 | 概览 | 今日待办 / 本月收支 / 笔记统计 三块基础看板 + 四个快速入口 |
| 2 | 待办 | 待办清单：场景、优先级、截止日期、完成勾选、筛选 |
| 3 | 笔记 | 笔记：场景分类、关键字搜索（标题 + 正文）、新建 / 编辑 / 删除 |
| 4 | 记账 | 收支记账：分类管理、按类型 / 分类筛选、月度统计、金额以**整数分**存储（零误差） |
| 5 | 学习 | 读书 / 课程 / 打卡 / 目标 四个 Tab，含连续打卡天数与月度聚合 |
| 6 | 工作 | 项目 / 工时 / 周报 / 日志 四个 Tab，周报可一键复制文本 |
| 7 | 生活 | 习惯打卡 / 健康记录 / 生活备忘 三个 Tab |
| 8 | 备份恢复 | 导出 JSON / 导出 CSV / 从 JSON 恢复（恢复前自动兜底备份） |
| 9 | 设置 | 主题（浅色 / 深色 / 跟随系统）、货币符号 |

## 二、数据放在哪里

**数据库**（SQLite，文件名 `personal_manager.sqlite`）：

```
%APPDATA%\com.personal\personal_manager\personal_manager.sqlite
```

> 实际路径由 `path_provider` 的「应用支持目录」决定，Windows 上就是上面这个位置。
> 想腾空间或换机迁移，**复制/备份这个文件即可**。

**导出的备份文件**：由你在「备份恢复」页里**自己选择目录**，文件名形如：

```
personal_manager_backup_20261012_003000.json
```

**恢复时的自动兜底备份**：在你选择的备份目录下自动建一个子目录

```
auto_backup_before_restore\
```

里面是**恢复前**的那份数据。万一恢复后发现选错了文件，可以从这里找回来。

## 三、常用操作

### 导出备份（JSON，推荐）

1. 左侧进入「备份恢复」
2. 点「导出 JSON」→ 选一个目录（建议 D 盘某文件夹，别选桌面）
3. 成功后目录里会出现 `personal_manager_backup_<时间戳>.json`

这个文件包含**全部 15 张表**的数据 + 格式版本 + 数据库版本 + 导出时间。
**建议定期导出并复制到 U 盘 / 网盘。**

### 导出 CSV（给 Excel / WPS 看）

点「导出 CSV」→ 选目录 → 生成 **15 个 CSV 文件**（每个文件名即表名）。
文件带 UTF-8 BOM，Excel / WPS **双击就能正确显示中文**，不会乱码。

> CSV 只用于查看 / 二次分析，**不建议**用它恢复数据（恢复请用 JSON）。

### 从备份恢复

1. 点「恢复」→ 选之前导出的 `.json` 文件
2. 弹出**覆盖警告**，确认后才会执行
3. 程序会先自动备份当前数据到 `auto_backup_before_restore\`，再校验版本，最后写回

**安全保证**：版本不对、文件损坏、字段缺失时**拒绝恢复且不动现有数据**。

## 四、常见问题

**Q：会联网吗？会收集我的数据吗？**
不会。整个程序**不请求任何网络**，数据只存在你本机。

**Q：金额为什么不用小数存？**
数据库里金额存的是**整数「分」**（`amountCents`）。浮点数存钱会有精度误差
（比如 `0.1 + 0.2 != 0.3`），整数分可以保证**零误差**。界面上仍显示元和两位小数。

**Q：误删了记录怎么办？**
drift 的事务 + 外键约束保证不会误删被引用的数据。若真删错了，用最近一次
JSON 备份恢复即可。

**Q：能开两个窗口同时用吗？**
不建议。SQLite 单文件并发写入可能导致锁冲突，**同一时间只开一个窗口**。

**Q：绿色版，怎么搬走？**
整个 `Release` 文件夹拷走就能用（**不能只拷 exe**，Dart 运行时和资源在同目录）。
数据不在这个文件夹里，需要单独迁移（见「数据放在哪里」）。
